## Self-Assessment

During my internship, I participated in the development of the **NASDAQ Stock Price Prediction & AWS Serverless ETL Pipeline** project. Throughout the internship, I was involved in different stages of the software development lifecycle, including AWS infrastructure setup, serverless application development, data collection, ETL processing, machine learning model implementation, API deployment, system testing, and documentation.

The internship provided me with valuable hands-on experience using AWS cloud services such as **Amazon S3, AWS Lambda, Amazon EventBridge, Amazon SQS, Amazon API Gateway, Amazon ECR, AWS Glue, Amazon Athena, and Amazon DynamoDB**. In addition, I improved my programming skills with **Python**, gained practical experience with **Docker**, learned how to build **RESTful APIs**, and applied **XGBoost** to solve a real-world machine learning problem.

Besides the technical knowledge, I learned how to work systematically, read technical documentation, troubleshoot problems independently, and communicate my progress with my supervisor. Although I successfully completed the assigned tasks, I recognize that I still have room to improve, especially in cloud architecture optimization, MLOps practices, large-scale data processing, and communication skills.

## Areas for Improvement

Although I successfully completed the internship objectives, I believe there are still several areas that I should continue improving in the future:

- Strengthen my understanding of MLOps practices, including CI/CD pipelines, automated model retraining, and model monitoring.
- Improve AWS cloud architecture design and cost optimization for large-scale production systems.
- Gain more experience with distributed data processing technologies such as Apache Spark and AWS EMR.
- Enhance software testing skills by applying more comprehensive unit testing, integration testing, and automated testing practices.
- Improve communication and technical presentation skills to explain complex system architectures and implementation decisions more effectively.
- Continue learning advanced AWS services and cloud-native design patterns to build more scalable and maintainable applications.
