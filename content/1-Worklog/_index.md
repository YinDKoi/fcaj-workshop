During the development of the **NASDAQ Stock Price Prediction & AWS Serverless ETL Pipeline** project, the internship activities were carried out over a period of **eight weeks**. Each week focused on a specific phase of the project, following the software development lifecycle from requirement analysis, AWS infrastructure setup, data collection, ETL processing, machine learning model development, system deployment, testing, and final project delivery.

The weekly progress is summarized as follows:

**Week 1:** [Project requirement analysis and AWS service research](1.1-week1/)

**Week 2:** [AWS environment setup and Serverless infrastructure configuration](1.2-week2/)

**Week 3:** [Developing the stock data collection pipeline using Yahoo Finance](1.3-week3/)

**Week 4:** [Developing the ETL pipeline and feature engineering](1.4-week4/)

**Week 5:** [Machine learning model development and evaluation](1.5-week5/)

**Week 6:** [Deploying the prediction service and REST API](1.6-week6/)

**Week 7:** [System integration testing, optimization, and documentation](1.7-week7/)

**Week 8:** [Project presentation, final documentation, and internship completion](1.8-week8/)
