### Kết quả đạt được:

* Đã nắm rõ mục tiêu của chương trình thực tập cũng như phạm vi của dự án **NASDAQ Stock Price Prediction & AWS Serverless ETL Pipeline**.

* Hiểu được kiến trúc tổng thể của hệ thống Serverless trên AWS và mối liên hệ giữa các thành phần trong pipeline xử lý dữ liệu.

* Hoàn thành việc nghiên cứu các dịch vụ AWS chính sẽ được sử dụng trong dự án, bao gồm:
  * Amazon S3
  * AWS Lambda
  * Amazon EventBridge
  * Amazon SQS
  * Amazon API Gateway
  * Amazon ECR

* Hiểu được quy trình xử lý dữ liệu từ thu thập dữ liệu chứng khoán, kiểm tra chất lượng dữ liệu, ETL, Feature Engineering, huấn luyện mô hình Machine Learning đến triển khai API phục vụ dự đoán.

* Chuẩn bị thành công môi trường phát triển, cài đặt đầy đủ các công cụ cần thiết và xác nhận các thành phần hoạt động ổn định.

* Nghiên cứu cấu trúc source code của dự án và xây dựng kế hoạch triển khai cho các giai đoạn phát triển tiếp theo.

* Hoàn thành các mục tiêu đề ra trong tuần đầu tiên và sẵn sàng bắt đầu xây dựng hệ thống trong tuần thứ hai.
