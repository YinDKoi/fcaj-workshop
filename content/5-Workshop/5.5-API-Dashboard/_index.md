#### API & Dashboard

After completing the data pipeline and deploying the Lambda Predictor, you can access prediction results through two different interfaces.

---

#### 5.1 — AWS API Gateway REST API

The `nasdaq-stock-predictor` Lambda function is exposed through **Amazon API Gateway** as a REST API endpoint.

**Endpoint:**

`POST https://<api-id>.execute-api.ap-southeast-1.amazonaws.com/prod/predict`

**Request:**

```json
{
    "ticker": "AAPL"
}
```

**Response:**

```json
{
    "ticker": "AAPL",
    "prediction": 1,
    "probability": 0.623,
    "label": "UP",
    "date": "2026-07-29",
    "features": {
        "RSI_14": 58.3,
        "MACD": 1.24,
        "BB_Width": 0.043
    }
}
```

Test the API using `curl`:

```bash
curl -X POST \
    "https://<api-id>.execute-api.ap-southeast-1.amazonaws.com/prod/predict" \
    -H "Content-Type: application/json" \
    -d '{"ticker": "AAPL"}'
```

*Figure 5.1. Testing the `/predict` endpoint exposed through Amazon API Gateway, demonstrating a successful request to the Lambda Predictor and the returned JSON response containing the predicted stock price direction, prediction probability, and generated technical features.*

#### 5.2 — Streamlit Dashboard (Local)

Launch the interactive Streamlit dashboard locally:

```bash
streamlit run dashboard/streamlit_app.py
```

Open your browser and navigate to:

`http://nasdaq-ai-dashboard-2026-430970051812-ap-southeast-1-an.s3-website-ap-southeast-1.amazonaws.com/`

The dashboard consists of two main pages:

- **Page 1 — Top Buy Signals:** Displays the stocks with the highest predicted upward movement based on the machine learning model.
- **Page 2 — Ticker Details:** Displays technical indicators, generated features, and recent prediction history for a selected stock ticker.
