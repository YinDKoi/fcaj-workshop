#### API & Dashboard

After completing the pipeline and deploying the Lambda Predictor, you can access predictions via two channels:

---

#### 5.1 — AWS API Gateway REST API

Lambda `nasdaq-stock-predictor` is exposed via **AWS API Gateway** as a REST endpoint:

**Endpoint:** `POST https://<api-id>.execute-api.ap-southeast-1.amazonaws.com/prod/predict`

**Request:**
```json
{"ticker": "AAPL"}
```

**Response:**
```json
{
    "ticker": "AAPL",
    "prediction": 1,
    "probability": 0.623,
    "label": "UP",
    "date": "2026-07-29"
}
```

![Amazon API Gateway Test](images/5/api-gateway-test.png)

*Figure 5.1. Testing the Amazon API Gateway `/predict` endpoint, demonstrating a successful request to the Lambda Predictor and the JSON response containing the predicted stock movement and probability.*

#### 5.2 — Streamlit Dashboard (Local)

```bash
streamlit run dashboard/streamlit_app.py
```

Open browser at `http://localhost:8501`.
