During the development of the **NASDAQ Stock Price Prediction & AWS Serverless ETL Pipeline** project, the work was completed over a period of **seven weeks**. Each week focused on a specific stage of the system development lifecycle, including requirement analysis, AWS infrastructure setup, ETL pipeline development, machine learning model training, deployment of prediction services, and final system validation.

The weekly progress is summarized as follows:

**Week 1:** [Project requirement analysis and AWS service research](1.1-week1/)

**Week 2:** [AWS environment setup and Serverless infrastructure configuration](1.2-week2/)

**Week 3:** [Building the data ingestion pipeline using Yahoo Finance](1.3-week3/)

**Week 4:** [Data quality validation and Quality Gate implementation](1.4-week4/)

**Week 5:** [Developing the ETL pipeline, feature engineering, and XGBoost model training](1.5-week5/)

**Week 6:** [Deploying the prediction service, REST API, and Streamlit dashboard](1.6-week6/)

**Week 7:** [System testing, performance optimization, and project documentation](1.7-week7/)
